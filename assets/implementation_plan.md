# Portfolio pour Maxime - BUT GMP 1ère année

L'objectif est de concevoir un portfolio moderne, très esthétique (thème sombre, accents bleus, glassmorphism, animations fluides), en HTML/CSS/JS pur.

## User Review Required

> [!IMPORTANT]
> Avant de commencer, pourriez-vous valider ce plan ? Notamment le choix des couleurs (thème sombre + bleu néon/tech) et la structure globale.
> 
> **Technologies** : HTML5, CSS3, JavaScript classique (aucun framework lourd n'étant requis, cela garantit d'excellentes performances).

## Proposed Changes

La structure sera la suivante, générée dans `c:\Users\AFE\projet porfolio Maxime` :

### Fichiers de code

#### [NEW] index.html
La structure de la page Web avec toutes les sections demandées.

#### [NEW] style.css
Le style de l'application (Thème sombre, variables de couleurs, animations CSS, responsive design, typography "premium").

Effets et dynamisme (animations d'entrée au scroll via IntersectionObserver, barre de progression dynamique, etc.).
